Python Discovery & Collection

Tests EDR/AV detection of Python-based reconnaissance and surveillance including system enumeration, screenshot capture, keylogger initialization, and file discovery — techniques used by RATs like PoetRAT, Machete, and InvisibleFerret.

📋 Overview

Discovery and collection techniques are used by adversaries to gather information about the target environment and collect sensitive data. This test evaluates whether your EDR can detect Python-based reconnaissance tools that enumerate system information, capture screenshots, monitor keyboard input, and traverse the file system.

These activities often occur early in an intrusion to help attackers understand what they've compromised and identify valuable data targets.

🎯 Capabilities Tested

1 System Enumeration

Gather OS, hostname, username, architecture info

platform.system(), socket.gethostname()

2 Network Discovery

IP addresses, network configuration, connections

ipconfig /all, netstat -an

3 Process Listing

Running processes, security software detection

tasklist, EnumProcesses()

4 Screenshot Capture

Desktop capture via GDI or PIL

GetDC(), ImageGrab.grab()

5 Keylogger Init

Keyboard state access, hook preparation

GetKeyboardState(), pynput

6 File Discovery

User directories, documents, sensitive files

os.listdir(), os.walk()

🔍 Detection Opportunities

Bulk Enumeration

Rapid sequential calls to system info APIs from a single process

Screenshot APIs

GetDC(0) or BitBlt calls from non-UI applications like Python

Keyboard Hooks

GetKeyboardState or SetWindowsHookEx from scripting processes

Directory Traversal

Rapid enumeration of user directories from Python

Command Execution

Python spawning ipconfig, tasklist, netstat

Network Scanning

Socket operations indicating host/port scanning

🛡️ MITRE ATT&CK Mapping

T1082 - System Information Discovery

Gather details about OS, version, patches, architecture, and hardware.

T1083 - File and Directory Discovery

Enumerate files and directories to find sensitive information.

Take screenshots to capture information displayed on screen.

T1056.001 - Keylogging

Record user keystrokes to capture credentials and sensitive data.
