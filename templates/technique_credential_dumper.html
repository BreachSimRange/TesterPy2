Python Credential Dumper

Tests EDR/AV detection of Python-based credential harvesting including SAM database extraction, LSASS memory access, DPAPI secrets, and Linux shadow file access. Techniques used by Mimikatz-style tools.

Overview

Credential dumping is a critical technique used by attackers to obtain account credentials for lateral movement and privilege escalation. This test evaluates whether your security solution can detect Python-based credential harvesting across different operating systems.

Unlike compiled tools like Mimikatz, Python-based credential access may evade signature-based detection while performing the same malicious activities.

Credential Targets

SAM Registry Windows

Security Account Manager contains local user password hashes. Requires SYSTEM privileges to read.

HKLM\SAM\SAM

LSASS Process Windows

Local Security Authority stores credentials in memory. Primary target for credential theft.

lsass.exe (PID varies)

DPAPI Secrets Windows

Data Protection API master keys can decrypt browser passwords, Wi-Fi keys, and more.

%APPDATA%\..\Local\Microsoft\Protect

Shadow File Linux

Contains hashed passwords for all system users. Requires root access to read.

/etc/shadow

SSH Keys Linux

Private SSH keys enable passwordless access to remote systems.

~/.ssh/id_*

Keyring/Wallet Linux

GNOME Keyring and KWallet store application passwords and secrets.

~/.local/share/keyrings/

Detection Opportunities

SAM Registry Access

Any non-SYSTEM process attempting to read HKLM\SAM\SAM

LSASS Access

OpenProcess with PROCESS_VM_READ (0x0010) on lsass.exe

DPAPI Enumeration

Non-browser process accessing Microsoft\Protect directory

Shadow File Read

Python process reading /etc/shadow (auditd)

MITRE ATT&CK Mapping

T1003.001 - LSASS Memory

Credentials stored in LSASS process memory can be extracted using various techniques.

T1003.002 - SAM

SAM database contains local account password hashes that can be cracked offline.

T1552.001 - Credentials in Files

Credentials stored in files like /etc/shadow or SSH keys.

T1555.004 - Windows Credential Manager

DPAPI protects credentials stored by Windows Credential Manager.
