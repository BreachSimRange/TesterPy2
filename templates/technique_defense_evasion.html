Python Defense Evasion

Tests EDR/AV detection of Python-based security product tampering including AMSI bypass, ETW patching, and ntdll unhooking. Techniques used to blind security solutions before executing malicious payloads.

Overview

Defense evasion techniques aim to disable or bypass security controls before executing malicious payloads. This test evaluates whether your EDR can detect when Python is used to tamper with security mechanisms like AMSI (Antimalware Scan Interface), ETW (Event Tracing for Windows), and API hooks placed by security products.

These techniques are often the first step in an attack chain; if successful, subsequent malicious activities may go undetected.

Evasion Techniques Tested

1 AMSI Bypass

Locates AmsiScanBuffer in amsi.dll to prepare for patching. Real attacks would patch this function to return "clean" for all scans.

GetProcAddress(amsi, "AmsiScanBuffer")

2 ETW Patching

Locates EtwEventWrite in ntdll.dll. Patching this disables security telemetry, blinding EDR solutions.

GetProcAddress(ntdll, "EtwEventWrite")

3 Environment Variables

Sets COMPlus_ETWEnabled=0 to disable CLR ETW events. Used to hide .NET-based payload execution.

os.environ["COMPLUS_ETWEnabled"] = "0"

4 Ntdll Unhooking

Reads clean ntdll.dll from disk to compare/replace hooked functions. EDRs hook ntdll to monitor syscalls.

open("C:\\Windows\\System32\\ntdll.dll", "rb")

Detection Opportunities

AMSI Loading

Non-standard processes loading amsi.dll, especially scripting interpreters

GetProcAddress Patterns

Resolving security-related exports: AmsiScanBuffer, EtwEventWrite

Ntdll File Access

Reading ntdll.dll from disk (normal processes use in-memory copy)

Environment Changes

Setting COMPLUS_ETWEnabled or similar evasion-related variables

What This Test Validates

  • AMSI integrity monitoring - Does EDR detect attempts to locate/patch AMSI functions?
  • ETW protection - Are attempts to disable ETW telemetry detected?
  • Self-protection - Can EDR detect unhooking attempts against its own hooks?
  • Environment monitoring - Are evasion-related environment variables flagged?
