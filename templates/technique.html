Command and Scripting Interpreter: Python

Adversaries may abuse Python commands and scripts for execution. Python is a very popular scripting/programming language with capabilities to perform many functions including system administration, data analysis, and malicious operations.

Description

Adversaries may abuse Python commands and scripts for execution. Python is a very popular scripting/programming language, with capabilities to perform many functions. Python can be executed interactively from the command-line (via the python.exe interpreter) or via scripts (.py) that can be written and distributed to different systems.

Python comes with many built-in packages to interact with the underlying system, such as file operations and device I/O. Adversaries can use these libraries to download and execute commands or other scripts as well as perform various malicious behaviors.

Python code can also be compiled into binary executables using tools like PyInstaller, py2exe, or Nuitka - making detection more challenging as the Python interpreter is bundled within the executable.

Why Python for Offensive Operations?

  • Cross-platform: Same code runs on Windows, Linux, and macOS with minimal modifications
  • Rich standard library: ctypes, subprocess, socket, os, and more provide low-level system access
  • Easy obfuscation: Code can be compiled, packed, or obfuscated to evade detection
  • Legitimate presence: Python is installed on many systems for development and automation
  • Rapid development: Quick iteration on payloads and tools
  • Living-off-the-land: Using Python that's already installed avoids dropping additional binaries

Test Scenarios in TESTERPy2

T001 Python Shellcode Loader

Tests detection of Python-based memory injection using ctypes for VirtualAlloc, memory copying, and thread creation. Emulates techniques from Donut framework and APT29's SeaDuke malware.
T002 Python Defense Evasion

Tests detection of security product tampering including AMSI bypass via AmsiScanBuffer patching, ETW provider manipulation, and ntdll unhooking.
T003 Python Credential Dumper

Tests detection of credential harvesting techniques including SAM database extraction, LSASS memory access, DPAPI decryption, and Linux shadow file access.
T004 Python Browser Stealer

Tests detection of browser data theft targeting Chrome, Firefox, and Edge for credentials, cookies, and session data. Emulates CookieMiner and Lumma Stealer.
T005 Python Discovery & Collection

Tests detection of reconnaissance and surveillance capabilities including system enumeration, screenshot capture, and keylogger functionality.

Detection Opportunities

Data Source Detection Logic
Process Creation Python.exe or py.exe with suspicious parent process (Office, LOLBAS)
Command Line Python executing encoded/base64 content or suspicious imports
API Monitoring Python process calling VirtualAlloc with PAGE_EXECUTE_READWRITE
File Access Python accessing browser profile directories or credential stores
Network Traffic Python making outbound connections to suspicious destinations
Module Load Python loading ctypes, pywin32, or other system interaction modules

Mitigations

  • M1049 - Antivirus/Antimalware: Use AV to quarantine suspicious Python scripts
  • M1047 - Audit: Inventory systems for unauthorized Python installations
  • M1038 - Execution Prevention: Denylist Python where not required
  • M1033 - Limit Software Installation: Prevent users from installing Python
